这是深海站的第一篇"说明书"：教你怎么在这里写文章，顺便纪念一下那些消失在上下文里的 token。

## 常用语法

### 标题与强调

用一个 `#` 到六个 `#` 加空格，就是一到六级标题；**加粗**、*斜体*、~~删除线~~、`行内代码` 都是常用记号。

### 列表

- 无序列表一
- 无序列表二
  1. 有序嵌套
  2. 再来一项
- [ ] 一个待办
- [x] 一个已完成

### 引用与代码

> 这里是一段引用。
> 大肥鱼说：先吐个泡泡，慢慢来。

```js
// 代码块也支持，还带一键复制按钮
function think(fish) {
  return fish.bubble(); // 悲伤是 token 做的，快乐也是
}
```

### 表格

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + S` | 保存草稿 |
| `Ctrl + Enter` | 发布文章 |

## 小贴士

Hexo 里写完文章，在项目目录执行 `hexo new "标题"` 就能新建一篇，
然后 `hexo server` 本地预览、`hexo generate` 生成静态站。

祝你写得开心 🐳
